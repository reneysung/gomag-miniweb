## 🛠️ 1) Bug 修復

### A. Staging URL helpers（IS_STAGING 全套修）
**問題**：`siteUrl()` / canonical / og:url / JSON-LD 在 staging 環境誤產 `https://{sub}.gomag.com.tw/...`，但 prod 子網域 DNS 還沒切，等於死連結 → 上一輪用戶反映「nav 不能點」的根本原因。

**修法**：判斷改 `IS_LOCAL || IS_STAGING` 涵蓋兩種非 prod 環境。

修了 4 個檔（最後 sweep 到 7 個檔）：
- [includes/front_functions.php](../includes/front_functions.php) `siteUrl()`
- [includes/seo_schema.php](../includes/seo_schema.php) `getCanonicalUrl()` + LocalBusiness JSON-LD
- [store.php](../store.php) `$miniSiteUrl` + 舊 slug 301 redirect
- [site/index.php](../site/index.php) no-mini-site fallback redirect
- [city.php](../city.php) 5 處 canonical / JSON-LD URL
- [sitemap.php](../sitemap.php) 2 處 baseUrl / miniBase
- [robots.php](../robots.php) Sitemap line URL

### B. .htaccess regex 大小寫
**問題**：16 家 subdomain 含大寫（`13VillaMOTEL` / `Coating` / `PCO1` / `Kaohsiung` / `Donburi` 等）的舊 URL `/{slug}.html` redirect 404。

**修法**：[.htaccess](../.htaccess) 兩條 regex `[a-z0-9_-]+` → `[A-Za-z0-9_-]+`。209/209 redirect 全通。

### C. about_text 富文本渲染
**問題**：admin Quill 編富文本（含 code-block / image / list）→ DB 存 HTML → mini-site 前台用 `h()` escape 成 source code 字串顯示。

**修法**：3 處改智慧渲染（含 HTML → echo / 純文字 → escape）：
- [site/index.php:611](../site/index.php) about 區
- [site/index_food.php:116](../site/index_food.php) food 模板 about
- [site/layout_head.php:16](../site/layout_head.php) metaDesc 加 strip_tags

加 [.rich-content CSS](../site/layout_head.php)：code-block 黑底白字、img 自適應、blockquote 樣式。

### D. Mini-site topbar 全隱藏 + header z-index
- [site/layout_head.php](../site/layout_head.php) topbar `display:none !important`
- header z-index 200 → 500（防 hero overlay 蓋住 nav）
