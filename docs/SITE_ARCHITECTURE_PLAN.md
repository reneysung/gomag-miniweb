## 一、現況：數據說了什麼

### 1.1 流量結構（近 3 個月）

全站 **3,820 點擊 / 27.9 萬曝光 / 平均排名 9.3 / 點閱率 1.4%**

| 頁型 | 頁數 | 點擊 | 佔比 | 每頁平均 |
|---|---:|---:|---:|---:|
| 店家行銷頁 `/store/*` | 261 | ~3,490 | **91%** | 13.4 |
| 清單頁 `/city/*` | 111 | 291 | 7.6% | 2.6 |
| 攻略文 `/guide/*` | 106 | **42** | 1.1% | **0.4** |

**結論：量產路線失敗。** 106 篇攻略文三個月換 42 點擊；111 個清單頁中 `/city/tainan/food/hotpot` 一頁就佔清單頁曝光的 45%。

### 1.2 流量的三種性質（不可混為一談）

| 性質 | 代表 | 可複製？ |
|---|---|---|
| **外部事件** | 洪廚 616 點擊＝電視《請世界吃桌》→「阿男師」品牌詞 | ❌ 會衰退，曲線已下滑 |
| **品牌詞** | 旭浪清潔 排 3.5、旭浪清潔評價 排 2.1 | ✅ 但天花板＝客戶自身知名度 |
| **發現型** | 小狀元「台南宅配晚餐推薦」16 點擊 | ✅ **這才是平台該做的** |

### 1.3 三個反直覺事實

**① 排名 ≠ 流量。** 台中辦桌推薦已排 **6.2 名，3 個月僅 8 曝光**。很多地區詞就算第一也沒量 → **選詞前必看 GSC 曝光，不憑感覺**。

**② 湊人數開關鍵字無效。** 汽車旅館 5 城各 5 家陪襯店，96 個查詢 3 個月僅 6 點擊；「台南永華春汽車旅館」排 3.2、44 曝光、**0 點擊**。

**③ 內容厚度差 8 倍。** gomag 清單頁平均 **534 字**；競品 nanushare 同類頁 **4,500–5,000 字**（結構：痛點→知識→比較表→價格表→店家清單→FAQ）。

嘉義 7 · 桃園 6 · 屏東 3 · 雲林 2 · 苗栗 1 · 彰化 1

**密度只集中在台南與高雄。** 其餘城市不具備開清單頁的條件。

## 二、已定案的架構原則

### 2.1 四種頁型的關鍵字分配

判準（依序問）：
```
① 詞裡有品牌名嗎？
   有 → ② 有「評價/心得/ptt/dcard/好不好」？ 有→行銷頁 ／ 沒有→小官網
   沒有 → ③ 要找店家 → 清單頁 ／ 要懂知識 → SEO 文
```

| 頁型 | 吃的詞 | 絕不碰 | 實測佐證 |
|---|---|---|---|
| **清單頁** `/city/*` | 台南辦桌、台南辦桌推薦、台南總鋪師 | 品牌名 | 內容太薄，未發揮 |
| **SEO 文** `/guide/*` | 粗清vs細清差在哪、一桌多少錢、流程 | 「{城市}{服務}推薦」 | 粗清vs細清 **點閱率 50%**（全站最高）|
| **小官網** `{sub}.gomag` | 旭浪清潔、品牌+電話/地址 | 類別詞（實測排 24–27）| 旭浪清潔 **排 3.5** |
| **行銷頁** `/store/*` | 旭浪清潔**評價**、ptt、好不好 | 類別詞、純品牌名 | 旭浪評價 **排 2.1** |

**標題公式**
```
清單頁：{城市}{服務}推薦｜{在地角度}
SEO 文：{疑問句}｜{補充}                    ← 不放「{城市}{服務}推薦」
小官網：{品牌全名}｜{城市}{服務}・{定位}     ← 品牌在最前
行銷頁：{品牌}評價・口碑推薦｜{城市}{服務}真實客戶評論
```

### 2.2 清單頁的開設條件（核心規則）

```
該「城市 × 子服務」的真實客戶數：
  ≥ 2 家 → 開清單頁，行銷頁退守品牌詞
  = 1 家 → 不開清單頁，讓該客戶行銷頁直接打類別詞
  = 0 家 → 不該有頁
```

**「1 家不開清單頁」的根據：** 清單頁存在的理由是「多家客戶互打」，1 家沒有這問題。小狀元 `/store/dinnerdelivery` **零標籤、零清單頁**，靠行銷頁自己吃下「台南宅配晚餐推薦」16 點擊，是全站最好的發現型案例。

### 2.3 陪襯店政策（Reney 2026-07-24 定）

```
該格有 ≥1 家真客戶 → 陪襯店全部下架（會稀釋真客戶曝光）
該格 0 家真客戶     → 陪襯店可留（沒有人被稀釋）
```
已依此刪除 17 家（280 → 263），保留 42 家（汽車旅館 25、台中清潔 8、台北清潔 3、新北細清 3、嘉義 3）。

## 四、待決策事項 🔴

### 4.1 網址結構：維持城市優先 or 改主題優先

| | 現行 gomag | 競品 twosevenths |
|---|---|---|
| 網址 | `/city/kaohsiung/beauty/massage` | `/therapy/massage-kaohsiung-osteopathy/` |
| 城市位置 | 路徑第 2 層 | **slug 裡的一個詞** |
| 層級 | 4 層 | 2 層 |
| 同一「城市×服務」可有幾頁 | **1 頁**（路徑固定） | **多頁**（各吃不同長尾） |

**觀察：** twosevenths 一樣能吃地方詞，靠的不是路徑層級而是 slug 內含城市。且層級淺 → 首頁直接連得到。

**但：** 架構是放大器不是解藥。內容還是 500 字的話，改架構只會從 111 個薄頁變成 300 個薄頁。

**選項**
- A. 維持現行架構，先補內容（風險最低）
- B. 改主題優先架構（需全站 301，工程大）
- C. 混合：新頁用新結構，舊頁不動（會有兩套並存的維護成本）

### 4.2 合約狀態欄位（阻塞項）

**DB 目前沒有任何合約/方案欄位**，無法分辨誰還在合約中。現有可用欄位只有 `is_featured`（60 家）、`has_minisite`（8 家）。

Reney 的規劃是「挑合約中的客戶先做主題，其餘為行銷頁」→ **必須先能標記客戶狀態**。

建議新增：
```sql
contract_status  ENUM('active','expired','trial','filler')  -- 合約中/已到期/試用/陪襯
contract_tier    ENUM('basic','standard','premium')          -- 方案等級（決定是否做主題）
contract_end     DATE
```

### 4.3 首頁內鏈（現況：0 條）

實測首頁連出去的內部連結：
```
店家行銷頁 26 個 · 分類頁 21 個 · 其他 23 個
子服務清單頁 0 個  ← 37 個清單頁全是孤兒
```
對照 twosevenths 首頁：`/therapy/*` 56 條、`/info/*` 36 條、各主題共 200+ 條，**幾乎全部指向內容頁**。

**首頁在推的東西（個別店家），跟決定要主打的東西（清單頁），完全是兩回事。**

### 4.4 Google 評分基礎建設

- 有 `google_place_id` 的客戶：**196 家（75%）**
- **但 DB 未存 rating / review_count**（前台即時打 API）
- 後果：清單頁**無法用評分排序、無法顯示 ★4.8**

competitor 的清單每家都帶 ★評分，這是說服力的主要來源之一。要走「攤開真實 Google 評價」的定位，此為前置作業（約 1 小時）。

### 4.5 定位（未定案）

- 「每個類別最多 5 家」目前**未做到**（台南餐飲 64 家、居家 31 家）。可行做法：清單頁只顯示真實客戶，不足 5 家就顯示實際數量 →「台南辦桌只推 2 家」反而有精選感。
- 不可宣稱：「Google 評價最好」（收的是簽約客戶非篩選最好）、「最多網友推薦」（testimonials 51 則中 28 則是 demo，只涵蓋 12 家）。
- 可宣稱：**「每一家都附真實 Google 評價，自己看了再決定」**（客觀、可驗證、與 twosevenths 的主觀評測區隔）。

### 主題頁標題公式

```
{城市}{服務}{疑問句}？{真實家數}家{角度}
```
例：`台南火鍋哪家最好吃？11 家在地人的口袋名單`

- 疑問句對到搜尋意圖（哪家最好吃／怎麼挑／差在哪）
- 數字必須是**真實家數**
- 關鍵字仍在最前，SEO 不受影響
- ⚠️ 不可用「不願告訴你的秘密基地」這類誇大——那些是簽約客戶，說法不成立且客戶會尷尬

**前提：標題承諾什麼，內容就要對得起。** 標「11 家口袋名單」但內容只有 668 字，跳出率會反傷排名 → **先做厚 1–2 個主題，首頁才有東西可推**。

## 五、頁型規格

### 5.1 清單頁（目標 3,000–4,000 字）

```
H1  {城市}{服務}推薦｜{知識角度}

[痛點] 第一次找{服務}不知道從哪問起
H2  {城市}的{服務}生態（在地知識，建立信任）
H2  {A} / {B} / {C} 差在哪（比較表）
H2  行情怎麼算（價格表，數字須人工核）
H2  怎麼挑（3–5 個檢查點）      ← 吃「{城市}{服務}怎麼選」
H2  不同場景怎麼做
     H3 {場景一}                ← 吃長尾
     H3 {場景二}
H2  {城市}在地{服務}店家         ← 客戶清單，每家 150–250 字
H2  常見問題（8–10 題）
```

**知識 6 : 客戶 4。** 客戶區塊每家含：一句定位、適合誰、3–5 個特色、Google 評價、基本資訊、「看完整介紹 →」連行銷頁。

**不會與行銷頁自我重複**——清單頁寫「比較用」資訊，行銷頁寫「決定下訂」資訊。

### 5.2 行銷頁

`{品牌}評價・口碑推薦｜{城市}{服務}真實客戶評論`
無小官網的客戶（263 家中約 255 家）兩角色一起扛：`{品牌}｜{城市}{服務}・{特色}`，仍不碰類別詞。

### 5.3 SEO 文

只寫「懂知識」型主題，標題用疑問句，不放「{城市}{服務}推薦」。
**現有 106 篇的處置待定**（3 個月 42 點擊）。
